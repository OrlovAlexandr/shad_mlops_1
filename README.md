# Shad MTS MLOps Project 1

Это учебный проект по MLOps, реализующий сервис для автоматической обработки входящих CSV-файлов, выполнения предсказаний с помощью обученной модели CatBoost и сохранения результатов.

Датасет можно найти [здесь](https://www.kaggle.com/competitions/teta-ml-1-2025/data).

## Структура проекта

```
.
├── app/                  # Основное приложение
│   └── app.py            # Сервис наблюдения за файлами и обработки
├── models/               # Обученная модель
│   └── my_catboost.cbm   # Сохранённая модель CatBoost
├── src/                  # Исходные модули
│   ├── preprocessing.py  # Предобработка данных
│   └── scorer.py         # Логика инференса модели
├── Dockerfile            # Файл для сборки докер-образа
├── requirements.txt      # Зависимости Python
└── README.md             # Readme файл
```

## Возможности

- Автоматическая обработка новых CSV-файлов в директории `/app/input`.
- Предобработка данных с извлечением новых признаков (временные метки, гео-расстояния).
- Предсказание с использованием обученной модели CatBoost.
- Визуализация плотности предсказанных вероятностей.
- Сохранение результата в виде:
  - CSV-файла с предсказаниями,
  - JSON-файла с ТОП-5 важными признаками,
  - PNG-графика плотности вероятностей.
- Точность модели F1 на Kaggle лидерборде - 0,905 / 0,922

## Как запустить

### Через Docker

1. Сборка образа:
```bash
docker build -t shad_mlops_1 .
```

2. Запуск контейнера:
```bash
docker docker run -it --rm -v ./input:/app/input -v ./output:/app/output shad_mlops_1
```

- Файл модели `my_catboost.cbm` должен быть в папке `models`.
- Директория `train_data' должна содержать обучающий датасет train.csv.

## Как использовать

1. Поместите CSV-файл с тестовыми данными в директорию `./input`.
2. Сервис автоматически обработает его и положит результаты в `./output`.


## Примеры вывода

- `predictions_*.csv` — предсказания модели.
- `top_5_features_*.json` — ТОП-5 самых важных признаков.
- `plot_probabilities_density_*.png` — график плотности вероятностей.

## Требования

- Python 3.11
- CatBoost
- Pandas
- Matplotlib / Seaborn
- Watchdog (для отслеживания файлов)

Необходимые зависимости указаны в `requirements.txt`.

## Логирование

- Логи записываются в файл `/app/logs/service.log`, а также выводятся в консоль.
- 3 уровня детализации: `INFO`, `WARNING`, `ERROR`.

## Используемые техники

- **Feature Engineering**: добавление временных признаков, вычисление расстояний (Haversine).
- **Мониторинг файловой системы**: автоматический запуск обработки новых файлов.
- **Модель**: загрузка готовой модели CatBoost.
- **Визуализация**: анализ уверенности модели через плотность вероятностей.
